# Design

Use existing dashboard/API contracts and existing importer/smoke infrastructure. Frontend owns concise status copy and controls; backend owns only compatibility-preserving data-state semantics and setup documentation. Preserve bounded bbox queries and all scientific classifications.

The UI will derive state from existing query results and errors rather than treating an empty response as zero. Simulation copy will identify synthetic fixture output and prohibit inference of prevalence, population, movement, hotspots, risk, completeness, or intervention effect. Rodent date inputs remain UTC API filters, with explicit inclusive range wording and matching feature count.

The current runtime login/North mismatch is an environment blocker, not a reason to bypass authentication or change unrelated application code.

# Proposal

## Why

Black-box and Impeccable review found a technically honest but cognitively dense dashboard. First-time analysts face a panel rail, technical simulation controls, tiny evidence labels, weak unavailable-layer next steps, and date filters that expose UTC mechanics.

## What Changes

- Reorder dashboard around map context, evidence orientation, synthetic demonstration, records, and provenance.
- Add responsive, accessible progressive disclosure and date presets.
- Keep synthetic reports and simulation outputs visibly independent.

## Scope

Redesign existing `apps/web` dashboard around one persistent map and progressive-disclosure task sections. Preserve APIs, MapLibre, evidence classes, provenance, synthetic-only boundaries, and existing uncommitted work.

## Outcome

A first-time user can orient, inspect map context, run the synthetic demonstration with sensible defaults, and understand its limits without developer knowledge. Advanced parameters, provenance, and raw attributes remain available but secondary.

## Non-goals

No new backend feature, database, dependency, state framework, real-data ingestion, biological claim, risk model, or mobile-native application.

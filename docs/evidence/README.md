# Evidence and parameter registry

Research traceability is required before a scientific claim or model parameter enters a decision-support path. Keep evidence separate from assumptions and simulated outputs.

Templates: `templates/literature-review.md`, `templates/evidence-record.md`, `templates/biological-parameter.md`, `templates/environmental-assumptions.md`, `templates/model-specification.md`, `templates/model-validation-report.md`, `templates/uncertainty-analysis.md`, `templates/data-provenance.md`.

Evidence records require evidence ID, title, authors, year, DOI/URL, study location, species, observation method, relevant findings, applicability to Taipei, limitations, confidence assessment, reviewer/date. Parameter records require ID, name, biological meaning, unit, source evidence IDs, distribution/range, justified default or `unknown`, calibration status and validation status.

Do not invent constants, confidence scores, validation results or causal claims. Preserve source/licensing constraints and evidence version history.
